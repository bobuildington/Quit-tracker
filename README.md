# Quit Tracker

A private, customizable quit tracker for GitHub Pages.

No account. No server. No sync. All data stays in the browser on the device that opens it.

## What it does

- Track anything you want to quit, not just one habit. Add as many trackers as you like.
- Every tracker is customizable: name, icon, color, unit name, cost per unit, usual amount per day, quit date and time, goal in days, and notes.
- Templates to start from (cigarettes, weed, vaping, alcohol, soda, coffee, snacks, or a blank custom tracker), and every template field can be edited.
- Live streak timer, money saved, and units avoided.
- Milestones at 1, 3, 7, 14, 21, 30, 60, 90, 180, 365, 500, 730, and 1000 days, plus an optional personal goal per tracker.
- Log cravings with one tap, and log slips without automatically erasing your streak. You can choose to reset the start date when you log a slip, or keep the timer running.

## Customize the app itself

Open **Customize app** in the header to change:

- App title
- Light or dark theme
- Accent color
- Currency symbol
- Whether money, units, milestones, and craving logging are shown

You can also export a JSON backup, import a backup, or erase everything from that same panel.

## Use it

1. Push this repo to GitHub (it is a single `index.html` file, plus this README).
2. In the repo on GitHub, go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
4. Wait a minute or two, then open `https://<your-username>.github.io/Quit-tracker/`

If the Pages branch dropdown is empty, the repo has no commits yet. Push `index.html` first, then the branch will appear.

## Privacy

Because there is no backend, there is nothing to sign into and nothing is sent anywhere. Backups are files you download yourself. If you switch devices, export on the old device and import on the new one.
